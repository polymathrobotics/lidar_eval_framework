# lidar_eval_framework

A framework for running, evaluating, and visualizing LiDAR performance and computed metrics in configurable environments.
See the documentation for more information: https://polymathrobotics.github.io/lidar_eval_framework/docs/intro

Here is a link to Polymath's personal data collection suite on all the Lidar's we've tested: https://polymath-lidar-eval-dashboard.streamlit.app/
